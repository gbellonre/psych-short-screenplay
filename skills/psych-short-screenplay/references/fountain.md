# Fountain

Default output is one Fountain code block so formatting survives copy-paste.

```fountain
Title: WORKING TITLE
Credit: Written by
Author: TBD
Draft date: YYYY-MM-DD
Draft: pass-name

==

FADE IN:

INT. LOCATION - NIGHT

Action in present tense. Photographable. No interiority unless it can be seen.

NAME
A short line.

NAME
(if needed)
Even shorter.
```

## Page rules

- Action lines: 1–3 sentences, concrete verbs, almost no adverbs.
- No `we see`, `the camera`, `CU`, `smash cut` in the literary draft.
- Character names consistent. Prefer short names.
- White space is a tool. Let silence exist on the page.
- Title in ALL CAPS, no subtitle cleverness.

Preserve any user line that already has bite. Do not sand it into generic literary horror.
