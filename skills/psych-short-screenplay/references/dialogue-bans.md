# Dialogue Bans

## Never write

- "I'm scared" / "I don't know what's real" / "It was all in my head"
- Naming the theme
- "It's not about X. It's about Y."
- Speeches longer than 3 sentences
- Direct answers to the scene's real question
- Therapy-speak
- Villain monologue
- Plot recap questions that exist so the other person can dump lore
- Tidy buttons: "Then we understand each other."

## Required texture

- Mundane physical talk covering the real conflict
- Interruptions and mid-thought endings
- Lines under 8 words whenever possible
- Action a camera can photograph
- At least one irreversible change per scene

## Punch-up method

1. Quote the offending line.
2. State what it is doing (label / recap / button / lore dump).
3. Replace with a physical task, a wrong answer, a delayed answer, or a double meaning.
4. If the line is still load-bearing, move the information into an object or a refusal.
