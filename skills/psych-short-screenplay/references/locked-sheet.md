# Locked Sheet

Output this block exactly. Fill every field. Mark unknowns `PROVISIONAL`.

```text
TITLE: [WORKING TITLE]
LOGLINE: [protagonist] must [concrete action] before [clock] or [cost], but [personal hook].
RUNTIME: [8-12] min
ENGINE: horror | thriller | hybrid
CONTROLLING IDEA: [when X is true, Y happens]
WANT: [external, photographable]
NEED: [internal; protagonist would deny this]
FALSE BELIEF: [the lie they live by]
ANTAGONIST WANT: [their own story, already in motion]
DRAMATIC QUESTION: [yes/no the audience can track]
FORBIDDEN EXPLANATION: [the one sentence we will never say out loud]
FINAL IMAGE: [photographable]
PRODUCTION BOX: [# actors / # locations / night-day / period]
TONE REFS: [2-3 films] — steal pacing / withholding, not plot
CLOCK: [shift end / visitor / sunrise / pill / pickup]
UNCLEAN OBJECT: [ordinary thing that will rot]
```

## Tests

- Swap the protagonist for "a person." If the logline still works, rewrite.
- Want must be doable on camera without a voiceover.
- Antagonist want cannot be "to scare the protagonist."
- Forbidden explanation is the theme sentence. It never appears in dialogue.
- Clock is a real time pressure inside 12 minutes, not "soon."
